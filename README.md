# 'Falling For It' Game
A runnable version of the game is in the FallingForIt V1.0.0 folder if you'd like to demo our game in it's current state.

A demo video for our game can be found here: https://drive.google.com/file/d/1cdM7u0O_9ebNjc4H51RHSMRTkMNsjYSZ/view?usp=drive_link

## Controls:
- WASD - Move
- Space - Jump
- Left Shift - Switch Gravity
- E - Interact With Button
