# 'Falling For It' Prototype
A runnable version of the game is in the PrototypeGame folder. 

A demo video for our game can be found here: https://drive.google.com/file/d/1cdM7u0O_9ebNjc4H51RHSMRTkMNsjYSZ/view?usp=drive_link

## Controls:
- WASD - Move
- Space - Jump
- E - Switch Gravity
- F - Interact With Button
