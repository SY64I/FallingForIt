# 'Falling For It' Game
A runnable version of the game is in the FallingForIt V1.0.0 folder if you'd like to demo our game in its current state.

A demo video for our game can be found here:
https://drive.google.com/file/d/1sEqiZy3jN6JdGZ4tO2-cOK9KgeCsBABa/view?usp=sharing

## Controls:
- WASD - Move
- Space - Jump
- Left Shift - Switch Gravity
- E - Interact With Button
